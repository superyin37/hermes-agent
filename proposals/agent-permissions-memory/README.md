## 当前设计方向

- 员工通过 Slack 交互，原始数据访问暂按方案 A，使用员工本人的数据访问资格信息。
- 历史、记忆、缓存、文件与其他派生内容独立执行访问控制。
- 默认保留个人长期记忆；团队与组织知识通过明确的发布流程共享。
- 是否采用独立部署，由执行隔离与业务域要求决定，不能仅按 bronze / silver / gold 层名划分权限。
