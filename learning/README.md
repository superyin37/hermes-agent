# Hermes 源码学习

这里集中保存 Skills、Tools、Agent Loop、Memory 等模块的学习计划和个人笔记。长期维护在 `docs/learning-notes` 分支，按模块和学习阶段分别提交。

## 学习路线与进度

建议先通过 Skills 建立“文件 → 上下文 → 工具调用”的认识，再学习 Tools 的执行机制、Agent Loop 的对话循环，最后理解 Memory 如何跨轮次和会话保留信息。顺序可以按实际疑问调整。

| --- | --- | --- | --- | --- |
| 1 | Skills | 指令文件如何被发现、加载并影响执行？ | [计划](skills/plan.md) · [笔记](skills/notes.md) | 计划与记录框架已创建；实验未开始 |
| 2 | Tools | 工具如何注册、暴露给模型、接收参数并返回结果？ | [待规划页面](tools/README.md) | 待规划 |
| 3 | Agent Loop | 用户消息、模型响应与工具结果如何构成循环？ | [待规划页面](agent-loop/README.md) | 待规划 |
| 4 | Memory | 哪些信息被保存，何时读取，怎样进入后续上下文？ | [待规划页面](memory/README.md) | 待规划 |

当前从 [Skills 阶段 0.1：确认代码与解释器](skills/plan.md) 开始。具体实验进度以各模块的笔记为准；完成一个阶段后再同步更新这里的摘要。

## 目录约定

```text
learning/
├── README.md
├── skills/
│   ├── plan.md
│   └── notes.md
├── tools/
│   └── README.md
├── agent-loop/
│   └── README.md
└── memory/
    └── README.md
```

- `plan.md`：操作步骤、阅读入口、实验设计、预期现象和完成标准。
- `notes.md`：个人猜测、实际运行证据、理解变化、疑问和进度。
- 未开展的模块用 `README.md` 保存目标与待研究问题。开始学习时，再补充该模块的 `plan.md` 和 `notes.md`。
- 文档里的源码链接相对于文档位置；命令的工作目录遵循每一步说明，通常是仓库根目录。阅读 `learning/` 中的文件不代表应当在该目录运行命令。

## 学习与记录方法

每次选择一个问题、一条实际代码路径和一个小实验。先预测，再观察，最后用自己的话解释。

将证据区分为代码阅读、直接函数运行、真实模型对话和已有测试。计划写完不等于实验完成，模型自述也不等于工具调用证据。记录源码提交与运行环境，便于日后复现。

可以自行填写笔记，也可以在对话后要求助手整理。例如：

> 请根据本次学习更新 learning/skills/notes.md。保留我的原始猜测，区分代码事实、实际运行结果和待验证推测，只勾选确实完成的步骤，并更新 learning/README.md 的进度摘要。

## 分支与维护

所有模块的学习资料共用 `docs/learning-notes`，不必每学一个模块就新建分支。需要修改源码做实验或贡献修复时，再单独创建实验或修复分支。

后续移动文档时，连同相对链接和对话中的更新路径一起调整。重要实验结果摘录到笔记中；密钥、令牌和包含凭据的配置不写入学习文档。
