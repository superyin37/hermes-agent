## 学习目标

区分会话历史、持久化记忆和技能中的程序性知识，理解信息如何被保存、读取并用于后续会话。

## 待研究问题

- 哪些状态只属于当前对话，哪些可以跨会话保留？
- 谁决定写入记忆，实际写入哪个文件或存储后端？
- 记忆何时被读取，怎样进入模型上下文？
- profile 隔离和会话缓存对记忆读写有什么约束？
- 内置实现与可选 memory provider 如何衔接？

## 学习路线

概念地图 → 最小文件读写 → 工具写入实现 → 冻结快照与模型上下文 → 前台／后台保存判断 → 会话历史检索 → Provider 契约 → 会话边界与压缩 → 隔离与可靠性 → 具体后端 → 综合验收。

与 Skills 并行维护进度，不要求先通读 Tools 或 Agent Loop；所需调用链在相应小节补齐。先从计划 0.1 的四个场景建立数据来源地图，不直接安装 provider 或启动模型。
