# Agent Loop 学习入口

返回[学习总览](../README.md)。状态：待规划，尚未开始实验。

## 学习目标

沿着一轮用户请求，理解消息如何装配、模型何时被调用、工具调用如何执行，以及循环何时继续或结束。

## 待研究问题

- 哪一层持有会话历史，哪一层负责一次模型请求？
- 模型返回普通文本和工具调用时，程序走哪些分支？
- 工具结果怎样被加入后续请求？
- 迭代预算、中断与上下文压缩怎样影响循环？
- 为什么保持系统提示词和历史前缀稳定很重要？

## 后续安排

在 Skills 和 Tools 的基础上，选择一次只调用一个工具的对话，再创建 `plan.md` 和 `notes.md`。先理解正常循环，再研究中断、压缩和失败恢复。
